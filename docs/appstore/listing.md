## Description (2,026 / 4,000)

```
NeoOne Keyboard lets you write any language the way you say it. Type it in English letters, as you would in a chat, and the suggestion bar offers the word in its own script: for example, type "mera" and get मेरा in Hindi, or "ente" and get എന്റെ in Malayalam.

TYPING
- Phonetic typing: type in English letters and pick the native-script word from the bar.
- Suggestions, autocorrect and next-word prediction in English and in each language you add.
- A native layout for each language, with its letters and signs, for when you'd rather type the script directly.
- Swipe typing.
- Emoji, with search, and emoji suggestions as you type.
- The keyboard learns the words you use. You can see them and forget them from the keyboard's settings.

UP TO FOUR LANGUAGES AT ONCE
Turn on up to four languages, English included. One language key switches between their layouts, and the suggestion bar works across all of them, so you can mix languages in the same message.

LANGUAGES
English is built in. Download the languages you want, free, from the Languages screen in the app; languages so far include Hindi, Malayalam and Assamese, with more to come. Or build your own language pack and import it from Files. Each language works offline once it is on your phone.

PRIVATE BY DESIGN
- Everything runs on your iPhone, and the keyboard works offline.
- The keyboard needs no Full Access, so it has no network access.
- The words it learns stay on your phone.
- No account, no ads, no tracking. The app collects no data.

SETTINGS
Hold the language key to open the keyboard's settings: turn languages on and off, choose how many suggestions to show, add a number row, turn autocorrect, emoji suggestions and key clicks on or off, and pick a theme and an accent colour.

GETTING STARTED
1. Open Settings → General → Keyboard → Keyboards.
2. Tap Add New Keyboard, then NeoOne Keyboard.
3. In any app, hold the globe key and pick NeoOne Keyboard.

Support: https://neoone.jishnu.me/support
Privacy policy: https://neoone.jishnu.me/privacy
```

## Review notes (1,273 / 4,000)

```
NeoOne Keyboard is a custom keyboard. No login or account is needed.

TO ENABLE THE KEYBOARD
1. Open Settings → General → Keyboard → Keyboards → Add New Keyboard.
2. Choose NeoOne Keyboard.
3. In any app (Notes, Messages), hold the globe key and pick NeoOne Keyboard.
The keyboard does not need Full Access. Please leave Allow Full Access off: everything works without it.

TO TRY MALAYALAM
1. Open the NeoOne Keyboard app and tap Languages.
2. Under Download, tap Get beside Malayalam (about 31 MB).
3. In Notes or Messages, switch to NeoOne Keyboard and type "ente". The suggestion bar shows എന്റെ; tap it to insert it. Hindi works the same way: download it, then type "mera" to get मेरा.
Hold the language key (to the left of the space bar) to open the keyboard's settings and turn languages on and off.

ABOUT LANGUAGE PACKS
Language packs are downloaded inside the app from https://neoone.jishnu.me. They are data only: word lists, keyboard layouts, romanisation tables and model weights, read by the app's own engine, which is compiled into the app. Packs contain no executable code and cannot change the app's behaviour beyond the words and layouts they provide. Each pack is checked before it is installed.

The app collects no data. Typing never leaves the device.
```
