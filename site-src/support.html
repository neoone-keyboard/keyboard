Common questions

How do I turn the keyboard on?

Settings → General → Keyboard → Keyboards → Add New Keyboard → NeoOne Keyboard. It does not need Full Access.

How do I add a language?

Open the NeoOne Keyboard app and choose Languages. Tap Get beside a language to download it, or import a .neopack file from Files. Up to four languages can be on at once; the keyboard picks up changes the next time it starts.

A download failed.

Check your connection and try again from Languages. Packs are checked before they are installed, so a failed or damaged download never replaces a working one.
