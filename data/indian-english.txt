# Indian English vocabulary for the English lexicon (en.fst), hand-written for this
# repository; see data/manifests/indian-english.json. One word per line, in the spelling
# the keyboard shows. `lexbuild --english-list` keeps every word here whatever its
# Wikipedia count (the count, when there is one, still ranks it).
#
# What belongs here: words people type in English sentences in India and Kerala that
# English Wikipedia uses too rarely to pass the unlisted-word threshold, so autocorrect
# "fixes" them (Vishu -> Fish, biryani -> Britain, PNR -> ONE).
#
# What does not: a lowercase word that is also the usual Manglish spelling of a Malayalam
# word (dosa, payasam, appam, puttu, sadya, vada, paisa, mundu, pooja ...). A word in the
# English lexicon is never replaced, so listing it would stop `dosa` ever becoming ദോശ.
# A word already in the lexicon keeps its own spelling (`pan`, not PAN): an all-capitals
# abbreviation of up to four letters is never autocorrected anyway (engine.rs, `Capitals`).
# Proper nouns are listed capitalised: a capitalised entry only matches a capitalised
# word, so lowercase Manglish (`onam`, `vishu`, `munnar`) still converts. Personal names
# are left out: a name at the start of a message is as likely Manglish as English.
